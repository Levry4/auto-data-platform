# Auto Data Platform

Учебный проект по построению Data Pipeline и локального Data Lakehouse для сбора, обработки и хранения данных об автомобилях.

## О проекте

Платформа получает данные об автомобильных марках через внешний API, обрабатывает их с помощью Python и Pandas и сохраняет в объектное хранилище MinIO.

Исходные данные сохраняются в формате JSON, обработанные - в формате Parquet. Для организации табличного хранения используется Apache Iceberg, управление каталогом выполняется через Lakekeeper, а для SQL-запросов используется Trino.

## Архитектура

1. **Extract** — получение данных из внешнего API.
2. **Transform** — обработка и преобразование данных с помощью Python и Pandas.
3. **Load** — сохранение исходных данных в JSON и обработанных данных в Parquet в MinIO.
4. **Data Lakehouse** — создание таблиц Apache Iceberg и управление метаданными через Lakekeeper.
5. **Query** — выполнение SQL-запросов к данным с помощью Trino.

## Технологии

- Python
- Pandas
- SQL
- Parquet
- MinIO
- Apache Iceberg
- Lakekeeper
- Trino
- Docker Compose

## Результат

В рамках проекта была развернута локальная инфраструктура Data Lakehouse, создана Iceberg-таблица и загружено **12 384 записи**. Корректность загрузки и доступность данных были проверены с помощью SQL-запросов в Trino.

## Запуск

Для запуска инфраструктуры используется Docker Compose:

```bash
docker compose up -d
```

Конфигурация сервисов и параметры подключения задаются в файлах проекта.
